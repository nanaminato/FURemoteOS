# UI Parity Matrix

| 页面/区域 | 必须复现 |
|---|---|
| MainWindow | 无系统标题栏、34px 自定义标题栏、窗口控制、连接栏 |
| Desktop Shell | wallpaper、桌面图标、Start menu、48px taskbar、内部窗口层 |
| Managed Window | caption、拖动、8px frame 圆角、resize、min/max/fullscreen、任务栏分组 |
| Modal | owner 遮罩、中心定位、可 resize、层叠、焦点链 |
| Explorer / Git | Tree、列表、选择和右键菜单 |
| Terminal / Editor | tab、工具栏、选择、复制粘贴、状态/错误 |
| Settings | 分页导航、主题与语言即时切换 |

逐页补充原始截图、布局尺寸、Loading/Error/Empty、Hover/Selected/Disabled/Focus 证据后，方可标 Completed。
